# APT-FusionNet

This repository contains the source code and experimental framework for our proposed **Dual-Branch CNN with Improved Gated Multimodal Fusion**. This model is designed for advanced multimodal sequence classification, specifically tailored for identifying Advanced Persistent Threat (APT) malware using both dynamic API call sequences and static feature sequences.
